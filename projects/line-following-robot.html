Autonomous Line-Following Robot

Designed, built, and programmed an ESP32-based autonomous robot capable of detecting and following a track using photoresistors and closed-loop feedback control.

ESP32 PID Control Photoresistors Embedded Systems Robotics

Overview

The goal of this project was to develop an autonomous mobile robot capable of navigating a track without direct human control. The robot used light sensors to determine its position relative to the track and continuously adjusted its wheel motion in response.

The project combined embedded programming, sensor calibration, motor control, mechanical design, and feedback control into a complete robotic system.

System Design

The robot was built around an ESP32 microcontroller that processed sensor measurements and generated commands for the motors.

ESP32 Main microcontroller responsible for sensor processing and control logic.
Photoresistors Measured reflected light to determine the robot's position relative to the track.
Motor Driver Controlled the DC motors based on commands generated by the ESP32.
Potentiometers Used during calibration and tuning of the sensing system.
3D-Printed Chassis Provided the mechanical structure supporting the electronics, motors, wheels, and sensors.
Light Shield Reduced interference from ambient lighting around the photoresistors.

Feedback & PID Control

Sensor measurements were used to estimate the robot's position relative to the track. The controller then adjusted the relative speed of the left and right motors to correct deviations from the desired path.

PID parameters and motor speeds were tuned to balance responsiveness and stability. More aggressive settings allowed faster response, while more conservative settings helped reduce overshoot during tighter sections of the track.

Calibration & Iteration

The sensing and control system required iterative calibration. Improvements included modifying the light shield to reduce ambient interference, adjusting the position of the photoresistor circuit, and tuning controller parameters for different track conditions.

This process demonstrated how mechanical design, sensing, and control software interact in a real physical system.
